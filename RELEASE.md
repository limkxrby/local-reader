# Local Reader 1.0.2 — release handoff

## Listing copy

Name: Local Reader

Summary: Save articles locally, read offline, import Pocket or Omnivore, and keep searchable notes and highlights. No account required.

Description: Build a library that stays on your device. Save an article with one toolbar click, read a clean text copy offline, organize it with tags, favorites and reading state, and highlight passages with personal notes. Bring existing Pocket CSV data or an extracted Omnivore export folder. Download imported links explicitly in batches. Export a complete JSON backup whenever you want. No analytics, account, subscription or cloud sync is required.

Privacy policy URL: https://github.com/limkxrby/local-reader/blob/main/PRIVACY.md

Support URL: https://github.com/limkxrby/local-reader/issues

Single purpose: Save, organize and annotate articles in a local offline reading library.

## Permission explanations

- activeTab: Read the current article after a toolbar or context-menu action.
- scripting: Run the bundled article extractor on the chosen page.
- contextMenus: Save articles and open the library from browser menus.
- Optional HTTP/HTTPS hosts: Request only the sites in a user-started download batch. Core features work without these grants.

No remote code is used. Third-party licenses are included in the extension ZIP. Publisher identity, contact details, account enrollment, privacy declarations, and final store submission must be completed by the project owner using their publisher account. Do not represent the listing as store-approved before review.

## Package and verification

Run `npm ci`, `npm run check`, and `npm run test:e2e` after installing Playwright Chromium. ZIP the contents of `dist/`, with manifest.json at the root. Store icon is `dist/icons/icon-128.png`. Screenshots generated by the browser test show actual fixture data; choose the 1280×800 store screenshots in the release bundle.

Automated coverage includes local persistence, legacy backup compatibility, metadata retention during recapture, trash restore, search, contextual highlights across formatted text, notes surviving offline reload, Pocket import, Omnivore metadata/HTML/Markdown import, bounded downloads and failure/retry.

Before public store publication, the owner should test native permission acceptance/denial, toolbar and context-menu capture, and extraction on their intended real sites in Chrome and Edge. Automated fixtures cannot establish compatibility with every publisher or browser configuration.

## Supported scope

Text-first offline reading; no offline images, video, PDFs, encrypted sync, or mobile extension. Downloads reject redirects and omit cookies; use toolbar capture for signed-in or JavaScript-rendered pages. Omnivore ZIP archives must first be extracted; Markdown highlight files are retained as searchable article notes rather than inferred inline anchors. Recoverable trash is included in backups. No project source license is selected yet.
